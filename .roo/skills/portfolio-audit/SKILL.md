# Enterprise Portfolio Standards

When auditing the project, apply these strict standards across the entire full-stack architecture:

## 1. Architecture & Structure
*   Ensure clean, modular separation of concerns between backend logic, frontend components, and database models.
*   Verify that API routes and integrations (e.g., RAG pipelines) follow RESTful or standardized patterns.

## 2. Code Quality
*   Enforce consistent naming conventions and modularity. 
*   Identify and suggest removals for any dead code, nested "callback hell," or overly complex functions.
*   Highlight missing type safety if using TypeScript.

## 3. Reliability & Edge Cases
*   Verify robust global error handling across both the frontend and backend.
*   Ensure proper loading states and graceful fallbacks for all AI/LLM integrations.

## 4. Documentation
*   Demand a professional `README.md` that includes: Project Purpose, Tech Stack, Architecture Overview, and clear setup instructions.
