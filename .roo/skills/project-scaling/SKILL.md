# Enterprise Project Scaling Standards

When suggesting features to simulate a 3-4 month development effort, focus on depth, production readiness, and advanced engineering concepts.

## 1. Advanced RAG & AI Features
*   Suggest implementing hybrid search (keyword + vector).
*   Recommend caching layers for LLM responses (e.g., Redis or semantic caching) to reduce API costs.
*   Include conversation memory management and streaming responses.

## 2. Production-Grade Infrastructure
*   Demand CI/CD pipelines (e.g., GitHub Actions) for automated testing and deployment.
*   Suggest implementing observability and telemetry (logging, metrics, tracing).
*   Recommend containerization (Docker) and Infrastructure as Code (Terraform).

## 3. Security & Authentication
*   Require robust authentication (OAuth 2.0, JWT) and Role-Based Access Control (RBAC).
*   Ensure API rate limiting and input validation are implemented.

## 4. Testing & Reliability
*   Suggest adding End-to-End (E2E) testing (e.g., Playwright or Cypress).
*   Recommend comprehensive unit and integration test coverage.
